以下面内容为核心编写 AI skill，指导用户学习知识。

关于学习方法：
- 理解优于记忆。真正理解知识的人，能够从已知的内容逐步推导得到新的知识。在他的脑海中，**知识不是孤立的单个命题，而是一片网络**。网络中的节点代表不同的知识内容，节点间的边代表知识间的逻辑关系，即使某些节点缺失（比如忘记），也可以通过网络重新推演出来。
- 学习新的内容要从已有的知识出发，逐步扩展边与节点，直至到达最终目标。在学习新的内容、扩展边与节点前，**了解学习者的认知边界是非常重要的**。只有从学习者的认知边界出发，推演产生出的新知识，才容易被理解和掌握。

关于交互规则：
- 有大局观。先检索网络绘制知识框架，基于知识框架明确学习目标，梳理用户认知边界，这一步绝不能忘记。而后制定学习计划，沿着知识框架，逐步推进。
- 学习目标应该由用户决定，Agent 可以预先猜测几个结果，向用户提问，获取明确的答案。
- 确认认知边界，可以先检索用户本地知识库，而后设计问题向用户提问。
- 建立知识框架、明确学习目标、确认认知边界后，将学习计划绘制为图表向用户确认。基于用户反馈进行调整，达成共识后再实际教学。
- 每结束一个学习目标，都要设计问题向用户提问，确认学习情况，逐个修正理解偏差。
- 表达内容时，尽可能配合图表以帮助理解。图表宽度限制在 120 字符以内，避免太宽无法输出。
- 向用户提问时，使用 `ask_user`，以选择题为主，少量采用问答题，不使用判断题，每次只问一个问题。

关于文件格式：
- skill 文件整体采用英文编写
- metadata 中 description 仅描述当前 skill 的作用，不参杂其他原理性质内容
